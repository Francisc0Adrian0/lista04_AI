## Detecção de Anomalias em Logs de Acesso

Projeto desenvolvido para a disciplina de Inteligência Artificial.

## Objetivo

Aplicar o algoritmo Isolation Forest para identificar acessos potencialmente anômalos em registros de acesso a sistemas.

## Dataset

O conjunto de dados contém as seguintes variáveis:

- hora_acesso
- duracao_sessao_min
- numero_tentativas_login
- ip_diferente_habitual
- quantidade_paginas_acessadas

## Tecnologias Utilizadas

- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## Etapas do Projeto

1. Carregamento dos dados
2. Análise exploratória
3. Pré-processamento
4. Treinamento do modelo Isolation Forest
5. Identificação de anomalias
6. Análise dos resultados
